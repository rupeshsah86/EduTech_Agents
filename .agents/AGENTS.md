# Project-Specific Rules for EduVerse AI

## Git Commit Style Guidelines
- Use simple, clear, and straightforward git commit messages describing exact work done.
- Example format: `update dashboard UI layout`, `fix light and dark theme colors`, `add notification feature`.
- Avoid overly complex, verbose, or long jargon in commit messages.

## UI & Theme Design Rules
- Maintain pure white / soft neutral background for Light Mode (`#FFFFFF` / `#FAFAFA`).
- Maintain deep charcoal background for Dark Mode (`#0A0A0A` / `#111111`).
- Never use blue theme backgrounds.
- Ensure all text colors adapt automatically to current theme with high contrast.
